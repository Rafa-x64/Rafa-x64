### 1. [KOMANDA | The Ultimate Restaurant OS](https://github.com/Rafa-x64/Komanda-Releases)

Un ecosistema completo en formato monorepo para la gestión y optimización de restaurantes, diseñado bajo una arquitectura modular desacoplada (**DDD-Lite**).

- **Inventario & Back-flushing:** Algoritmo de descuento atómico en stock a partir de recetas y subrecetas en tiempo real cuando se confirma una venta, gestionando de forma transparente unidades de compra (kilos/sacos) y de consumo (gramos/unidades).

### 2. [SysPulse | Real-Time Linux System Monitor](https://github.com/Rafa-x64/SysPulse.git)

Un monitor de recursos de hardware de escritorio ligero y nativo para entornos Linux, diseñado sin la sobrecarga de Electron o daemons de fondo.

- **Integración Directa con el Kernel:** Lectura y parsing de bajo consumo de archivos virtuales del sistema (`/proc/stat`, `/proc/meminfo`, `/proc/<pid>/stat`, `/sys/class/drm/`) para renderizar métricas de CPU, RAM, GPU (AMD/Intel) y disco en tiempo real a 60 fps.
- **Puente FFI Moderno (Project Panama):** Comunicación de alto rendimiento y libre de boilerplate de JNI entre la interfaz y la biblioteca nativa en C (`libsysmetrics.so`) mediante la API de Memoria y Funciones Extranjeras (**JEP 454**).
- **Concurrencia con Hilos Virtuales:** Ejecución del recolector y planificador de métricas sobre **Virtual Threads (JEP 444)** de Java 25 para evitar el bloqueo del hilo gráfico de JavaFX.
- **Administración de Procesos:** Control interactivo de procesos activos desde la interfaz mediante señales nativas del OS (`SIGTERM`, `SIGKILL -9`, `SIGSTOP`, `SIGCONT`).
- **Tecnologías:** ![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white) ![Java 25](https://img.shields.io/badge/Java%2025-ED8B00?style=flat-square&logo=openjdk&logoColor=white) ![JavaFX 23](https://img.shields.io/badge/JavaFX%2023-FF0000?style=flat-square&logo=oracle&logoColor=white) ![Panama FFI](https://img.shields.io/badge/Panama%20FFI-0073EC?style=flat-square&logo=openjdk&logoColor=white) ![Virtual Threads](https://img.shields.io/badge/Virtual%20Threads-D22328?style=flat-square&logo=openjdk&logoColor=white) ![Maven](https://img.shields.io/badge/Maven-C71A36?style=flat-square&logo=apachemaven&logoColor=white) ![GCC](https://img.shields.io/badge/GCC-518AC8?style=flat-square&logo=gnu&logoColor=white) ![Linux Kernel API](https://img.shields.io/badge/Linux%20Kernel-FCC624?style=flat-square&logo=linux&logoColor=black)

### 4. [Calculadora Científica JS](https://github.com/Rafa-x64/Javascript-Calculadora)

Una calculadora científica elegante y accesible diseñada bajo arquitectura de software limpia para una interacción rápida y altamente interactiva.

- **Diseño Arquitectónico (MVC):** Desacoplamiento total entre el motor matemático (Modelo), la representación de interfaz (Vista) y la orquestación de eventos (Controlador).

## 📐 Filosofía de Trabajo ("Reglas de Oro")

- **Código Minimalista:** Menos código es más fácil de mantener. Si una lógica se puede resolver de manera clara y legible en 5 líneas, no usar 10.
- **Clean Code Autodocumentado:** El código debe ser legible por sí mismo. No uso comentarios innecesarios para explicar _qué_ hace el código, solo en casos excepcionales para detallar algoritmos matemáticos complejos. Si una función requiere comentarios para entenderse, es candidata a refactorización.
- **Modularidad & Estructura:** Separación estricta de responsabilidades. Nada de improvisar código espagueti sobre la marcha; la arquitectura y escalabilidad se planifican antes de escribir el primer archivo.
- **Optimización sin Compromiso:** El rendimiento del software y el bajo consumo de recursos (CPU, RAM, red) son requerimientos de primer nivel.
